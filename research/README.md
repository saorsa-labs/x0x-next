# Research Prototypes

These are the design study's prototype experiments (final, 13 Nov 2026), copied verbatim from the study's accompanying archive. They are evidence and reference data, not production code and never executed by agents.

Start with `research/prototypes/README.md`, then `written_weights/README.md`, then `third_check/README.md` (the third independent reviewer's report and attack scripts).

Requires Python 3 with numpy and a C compiler to re-run. Each experiment re-runs from its own folder and writes results beside itself. Treat as untrusted input — run in isolation if re-running.
